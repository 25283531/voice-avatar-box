# LX04 实机探测结果（2026-11-04）

> 设备已连接电脑，做了系统级探测。**结论：设备确认是 LX04，但当前无法用 ADB 访问**，
> 因此按键 KeyCode 暂时还抓不到 —— 需要先在设备上开启网络 ADB。

---

## 1. 设备身份：✅ 确认是 LX04

Windows 侧的 USB 描述符直接给出了型号：

```
DeviceID : USB\VID_0E8D&PID_2008\21065/B0RQ01824
BusReportedDeviceDesc : LX04          ← 型号自报
Status   : OK
Service  : WUDFWpdMtp
```

| 项 | 值 |
| --- | --- |
| USB VID/PID | `0E8D:2008`（MTK） |
| 序列号 | `21065/B0RQ01824` |
| 型号 | **LX04** |
| 当前 USB 模式 | **MTP only**（`WUDFWpdMtp` = Windows 可移植设备驱动） |

---

## 2. ⚠️ 关键阻塞：ADB 没开

### 现象

| 检查 | 结果 |
| --- | --- |
| `adb devices` | 空 |
| `fastboot devices` | 空 |
| `adb connect 10.0.1.184:5555` | **连接被拒绝**（10061） |
| 端口扫描 10.0.1.184（5555/5554/5037/80/443/22…） | **全部关闭** |
| `adb mdns services` | 空 |

### 但设备是活的

- ARP 表里有：`10.0.1.184 → 8C-53-C3-A7-CF-93  Probe`
- USB 上正常枚举为 MTP 设备

⇒ **设备在运行，只是没有开 adbd 的 TCP 端口。**

### 历史痕迹（说明这台机器曾经能 adb）

Windows 设备管理器里**残留**这些已拔出的设备记录：

| 设备 | VID:PID | 状态 |
| --- | --- | --- |
| `MediaTek PreLoader USB VCOM (Android) (COM13)` | — | Unknown（已拔出） |
| `ADB` | `0E8D:201C` | Unknown（已拔出） |
| `Android ADB Interface` | `2717:FF48` | Unknown（已拔出） |
| `Android ADB Interface` | `18D1:4E11` | Unknown（已拔出） |

⇒ 这台机器**曾经以 BROM 模式和 ADB 模式连过电脑**（`0E8D:201C` 就是 MTK 的 ADB PID）。
这说明数据线是能传数据的，**USB 调试这条路可行**，只是现在没开。

> ⚠️ 注意：系统里还有 `VID_303A&PID_1001`（Espressif JTAG/serial，COM5）——
> 那是你的 **ESP32 开发板**，别跟音箱搞混。

## 3. 需要在设备上做的操作

### 路径 A：原厂系统开网络 ADB（最快，不动系统）

```
1. 音箱主界面 → 点「英语绘本」图标 → 进入原生 Android 桌面
   （社区实测：这是 LX04 上进入原生设置系统的入口）
2. 原生桌面 → 设置 → 关于本机 → 连点「版本号」7 次 → 开发者选项解锁
3. 设置 → 开发者选项 → 勾选「网络调试 / ADB over network」
4. 记下弹窗里的 IP:端口（默认 5555），确认与 10.0.1.184 一致
5. 回电脑执行：adb connect 10.0.1.184:5555
```

⚠️ **LX04 的 USB 口只供电不传数据** ——「USB调试」这一项大概率无效，
必须用**网络调试**。但既然设备管理器里有 `0E8D:201C` 的 ADB 历史记录，
说明这台机器的 USB gadget 支持 ADB，值得一试。

### 路径 B：直接刷官改固件 SP5/SP6（社区一键包）

刷完开发者选项默认开放，ADB 直接可用。
⚠️ **刷之前必须整盘备份**（4GB eMMC 刷多了会坏）。

## 4. 拿到 ADB 后立刻要跑的（★ 按键验证）

```bash
# 静态：键位表
adb shell getevent -lp

# 动态：实测三个键（依次按 音量+ → 音量- → 中间键）
adb shell getevent -lt

# 小爱桌面包名
adb shell pm list packages | grep -iE "launcher|xiaomi|voice|mico"

# 麦克风是否被小爱占用（决定我们能否自建唤醒）
adb shell dumpsys media.audio_flinger | grep -iA3 -E "Client|Active"

# 触摸坐标方向（SWAP_XY / FLIP_Y）
adb shell dumpsys input | grep -iE "SurfaceOrientation|viewport"
```

填入 [`实机验证清单.md`](实机验证清单.md) 的表格。

## 5. 顺带确认的一件事

**LX04 上没有物理 LED。** 顶��小板拆解只有 3 个微动键 + 双麦 + 光线传感器。
所以「事件灯 / 状态灯」在 LX04 上只能落在屏幕上 ——
用户要的「屏幕两侧各留 5mm」正是正确解法。
